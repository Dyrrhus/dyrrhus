# Dyrrhus

**A Bilingual AI Platform for Bangladesh**

Dyrrhus is a bilingual AI platform built from scratch to provide information about Bangladesh's locations, covering history, economy, culture, and nature. It uses custom Bangla–English tokenization, cross-lingual retrieval, and a self-developed language model, while helping our team learn AI engineering from the ground up.

## Core Features

- Bilingual interaction (Bangla and English)
- Bangladesh-focused geographic knowledge
- Custom Bangla–English tokenization
- Cross-lingual information retrieval
- Self-developed language model

## Research & Development
